# Simon Memory Game 🧠

## Project Overview
The *Simon Memory Game* is an interactive web-based pattern-matching game. It challenges users to memorize and repeat an ever-increasing sequence of colors and sounds, testing both cognitive memory and real-time user interaction handling.

## Why I Built This
This project was a deep dive into *jQuery* and *State Management*. I wanted to master the logic of tracking "Game State" (the sequence generated by the computer) versus "User State" (the sequence clicked by the player) and comparing them in real-time.

## Key Features
* *Dynamic Pattern Generation:* Uses JavaScript math logic to generate random, unpredictable sequences.
* *Synchronized Audio-Visuals:* Integrated CSS3 Keyframe animations with the HTML5 Audio API for an immersive experience.
* *Adaptive Difficulty:* The game logic automatically increases speed and complexity as the user reaches higher levels.
* *Robust Logic Validation:* A custom "Check Answer" function that validates user input at every step of the sequence.

## Technical Skills Applied
* *jQuery:* Simplified DOM manipulation and event handling.
* *JavaScript:* Arrays, functions, and conditional "Game Over" logic.
* *CSS3:* Keyframe animations for the "pressed" and "game-over" visual effects.
